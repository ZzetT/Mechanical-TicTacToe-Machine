# Fonts

All text on the parts (card numbers, cover lettering, indicator plates,
signature) uses **Liberation Sans**. The font files are bundled so that
`ttt_machine.py` produces exactly the same text geometry on every computer,
independent of the fonts installed on the system.

| File | Style |
|---|---|
| `LiberationSans-Regular.ttf` | card numbers |
| `LiberationSans-Bold.ttf` | cover lettering, indicator plates |
| `LiberationSans-BoldItalic.ttf` | signature on the mid frame |
